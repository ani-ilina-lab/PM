# Релизный поезд за 5 минут

Интерактивная схема для новичков: как работает релизный поезд и релизный план.

- `index.html` — самодостаточный файл, открывается двойным кликом в браузере, без интернета.
- Девять этапов рейса с документами на каждом шаге.
- Приоритеты Must / Should / Could.
- Симулятор типовых проблем: что делать, если что-то пошло не так.
- Роли и страховки (feature flags, откат, мониторинг, поэтапная раскатка).
